## 👨‍💻 Panduan Pengembangan (Developer Notes)

Bagian ini ditujukan bagi pengembang yang ingin menjalankan proyek ini secara lokal.

### Tech Stack
- **Framework**: Next.js (App Router)
- **Library**: React, Tailwind CSS
- **Database**: PostgreSQL
- **Storage**: S3 Compatible (MinIO)

### Cara Menjalankan Lokal
1. Install dependencies:
   ```bash
   npm install
   ```
2. Konfigurasi Environment:
   Salin `.env.example` menjadi `.env.local` dan isi nilai yang diperlukan.
3. Jalankan Aplikasi:
   ```bash
   npm run dev
   ```
4. Setup Database (Opsional):
   ```bash
   npm run db:setup-admin
   ```
